# Платформа мобильного робота

Проект базовой программно-аппаратной платформы для студенческих исследований.

## Цель проекта
Оживить существующее шасси робота, настроить управление движением, подключить базовый комплекс сенсоров (лидар, камеры, гироскоп), разработать удобный веб-пульт оператора на React и предоставить открытый программный интерфейс (API + плагины), чтобы следующие студенты могли сразу писать прикладные алгоритмы (автономную навигацию, компьютерное зрение).

---

## Что нужно сделать и как проверить

### 1. Шасси и движение
* **Задача:** подключить моторы и энкодеры к контроллеру, настроить плавный ход, повороты и экстренное торможение.
* **Проверка:** робот ровно едет вперед/назад, слушается команд и моментально останавливается при обрыве связи.

### 2. Сенсоры
* **Лидар:** считывать расстояния до препятствий вокруг робота (на 360°).  
  *Проверка:* четко видит препятствие перед собой и определяет расстояние до него.
* **Камера:** передавать видеопоток на пульт.  
  *Проверка:* картинка в браузере идет плавно и без задержки.
* **Гироскоп (IMU):** определять ориентацию и наклоны робота.  
  *Проверка:* при физическом повороте робота в руках углы в телеметрии адекватно меняются.

### 3. Мок-режим (тестирование без робота)
* **Задача:** программная имитация датчиков и движения, чтобы можно было разрабатывать код дома на ноутбуке.
* **Проверка:** сервер запускается без физического робота, отдает виртуальные показания и принимает команды.

### 4. Веб-пульт оператора (React)
* **Задача:** удобный интерфейс в браузере для управления роботом с ноутбука или смартфона.
* **Что на экране:** виртуальный джойстик (или клавиши WASD), видео с камеры, радар лидара, заряд батареи и кнопка «СТОП».
* **Проверка:** открываем страницу в браузере, жмем кнопки — робот (или мок) реагирует без задержек.

### 5. API и плагины для студентов
* **Задача:** простой программный интерфейс (на Python), чтобы студенты могли подключиться к роботу в несколько строк кода.
* **Проверка:** работает тестовый студенческий скрипт (например: *«если впереди преграда ближе 0.5 м — повернуть в сторону»*).
