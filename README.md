# 🤖 Платформа мобильного робота (Student Robotics Platform)

Открытая модульная программно-аппаратная платформа для студенческих исследовательских и прикладных проектов в области мобильной робототехники.

---

## 🎯 Цель проекта

Главная цель — вдохнуть жизнь в существующее мобильное шасси робота, объединить базовый сенсорный комплекс, создать удобный веб-пульт управления и предоставить чистый, документированный программный интерфейс (API + система плагинов).

Благодаря такой архитектуре следующим поколениям студентов и исследователей не придется тратить недели на рутинную низкоуровневую настройку моторов и протоколов связи: они смогут **сразу сосредоточиться на создании прикладных интеллектуальных алгоритмов** (автономная навигация, SLAM, компьютерное зрение, машинное обучение).

---

## 🚀 Ключевые направления разработки

### 1. 🏎️ Оживление шасси и управление движением
- Подключение и калибровка драйверов двигателей и энкодеров.
- Настройка кинематической модели движения робота.
- Реализация ПИД-регуляторов скорости и стабилизации курса.
- Механизм плавного разгона/торможения и защитный аварийный останов (E-Stop).

### 2. 📡 Сенсорный комплекс
- **Лидар (LIDAR)**: Сбор 2D/3D облака точек, фильтрация шумов, трансляция лазерного скана для картографирования и объезда препятствий.
- **Камеры**: Потоковое вещание видео с малой задержкой (WebRTC / MJPEG / RTSP) для FPV-управления и инференса нейросетей.
- **IMU (гироскоп + акселерометр)**: Определение угловой ориентации (pitch/roll/yaw), фильтрация (Кальман / Маджвик), расчет одометрии.

### 3. 🌐 Веб-пульт оператора (React UI)
- Современный отзывчивый веб-интерфейс, работающий в браузере на ноутбуке, планшете или телефоне.
- **Виртуальный джойстик** и поддержка управления с клавиатуры / аппаратного геймпада.
- Потоковый вывод видео с бортовых камер в реальном времени.
- Визуализация карты / данных лидара и ориентации робота в пространстве (3D-виджет IMU).
- Телеметрия: напряжение и заряд аккумулятора, температура контроллеров, пинг, статус сенсоров.

### 4. 🔌 Открытый программный интерфейс (API + Плагины)
- Высокоуровневый API (REST / WebSocket / ROS 2 bridge) для чтения сенсоров и отправки скоростей (`linear.x`, `angular.z`).
- **Модульная система плагинов**: изоляция пользовательских сценариев.
- Готовые шаблоны плагинов для студентов:
  - Автономный обход препятствий по лидару;
  - Детекция объектов и людей по камере (YOLO);
  - Следование по визуальной линии или ArUco-маркерам;
  - Построение карты помещения (SLAM).

## 🎓 Руководство для студентов: как написать свой плагин

Каждый плагин представляет собой независимый модуль, который подписывается на потоки данных робота и отправляет команды управления.

Пример простого плагина на Python:

```python
from robot_sdk import RobotClient

robot = RobotClient(host="192.168.1.100")

def on_lidar_scan(scan_data):
    # Если препятствие впереди ближе 0.5 метра — останавливаемся и поворачиваем
    if scan_data.min_front_distance < 0.5:
        robot.drive(linear_speed=0.0, angular_speed=0.5)
    else:
        robot.drive(linear_speed=0.3, angular_speed=0.0)

robot.subscribe_lidar(on_lidar_scan)
robot.run()
```
